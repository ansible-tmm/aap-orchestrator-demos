# Contributing

Thanks for helping grow the automation orchestrator demo marketplace.

**Full guide (recommended):** [Contribute a demo](https://ansible-tmm.github.io/aap-orchestrator-demos/contribute/) on the GitHub Pages site — fork setup, GitHub Pages preview, minimum files, and how to open a PR.

## Short path

1. Fork [ansible-tmm/aap-orchestrator-demos](https://github.com/ansible-tmm/aap-orchestrator-demos) (keep the repo name so Pages URLs work).
2. Enable **Settings → Pages → Deploy from a branch** on your fork and preview at `https://<you>.github.io/aap-orchestrator-demos/`.
3. Add a demo folder plus catalog entries in `_data/demos.yml`, `_data/demo_pages.yml`, `_data/demo_playbooks.yml`, and `demos/<slug>/index.html`.
4. Open a PR against `main` with a short description and your Pages preview link.

See [DEVELOPER.md](DEVELOPER.md) for deeper technical notes.
